Which of the following is equivalent to $\dfrac{x^2 - 9}{x^2 + x - 6}$ for all $x \ne 2$ and $x \ne -3$?
  1. $\dfrac{x + 3}{x - 2}$
  2. $\dfrac{x - 3}{x + 2}$
  3. $\dfrac{x - 3}{x - 2}$
  4. $\dfrac{x + 3}{x + 2}$
  5. $\dfrac{x - 3}{x + 3}$
Answer C. Factorise: $x^2 - 9 = (x - 3)(x + 3)$ and $x^2 + x - 6 = (x + 3)(x - 2)$. Cancelling $x + 3$ leaves $\frac{x - 3}{x - 2}$.
tmua-diagnostic-p1-02 · Algebra and functions · Equations and inequalities · difficulty 2
What is the complete set of values of $x$ for which $x^2 - 5x + 4 < 0$?
  1. $x < 1$ or $x > 4$
  2. $1 < x < 4$
  3. $-4 < x < -1$
  4. $x < -4$ or $x > -1$
  5. $x < 4$
Answer B. $x^2 - 5x + 4 = (x - 1)(x - 4)$, a parabola opening upwards with roots $1$ and $4$. It is negative between the roots: $1 < x < 4$.
tmua-diagnostic-p1-03 · Algebra and functions · Exponentials and logarithms · difficulty 2
Find all real solutions of $\log_2 x + \log_2 (x - 2) = 3$.
  1. $x = -2$
  2. $x = 2$
  3. $x = -2$ and $x = 4$
  4. $x = 4$
  5. $x = 6$
Answer D. Combine the logs: $\log_2 (x(x - 2)) = 3$, so $x^2 - 2x = 8$ and $(x - 4)(x + 2) = 0$. The logarithms need $x > 2$, so $x = -2$ is rejected and only $x = 4$ remains.

tmua-diagnostic-p1-05 · Calculus · Differentiation · difficulty 2
The curve $y = x^3 - 6x^2 + 9x + 1$ has two stationary points. What is the $y$-coordinate of the local minimum?
  1. $1$
  2. $3$
  3. $5$
  4. $7$
  5. $9$
Answer A. $\frac{dy}{dx} = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)$, so the stationary points are at $x = 1$ and $x = 3$. A positive cubic has its minimum at the larger one: $y(3) = 27 - 54 + 27 + 1 = 1$.
tmua-diagnostic-p1-06 · Calculus · Integration · difficulty 3
What is the area of the finite region enclosed by the curve $y = x^2$ and the line $y = 2x$?
  1. $\dfrac{1}{3}$
  2. $\dfrac{2}{3}$
  3. $1$
  4. $\dfrac{4}{3}$
  5. $\dfrac{8}{3}$
Answer D. They meet where $x^2 = 2x$, at $x = 0$ and $x = 2$. Between them the line is above the curve, so the area is $\int_0^2 (2x - x^2)\,dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 = 4 - \frac{8}{3} = \frac{4}{3}$.

"If a whole number is divisible by $6$, then it is divisible by $3$."


Which of the following is the contrapositive of this statement?
  1. If a whole number is not divisible by 3, then it is not divisible by 6.
  2. If a whole number is divisible by 3, then it is divisible by 6.

tmua-diagnostic-p2-06 · Logic · Necessary and sufficient conditions · difficulty 3
Let $f(x) = x^3 + ax + b$, where $a$ and $b$ are real constants. Consider the statements:


I: If $a > 0$, then $f(x) = 0$ has exactly one real root.
II: If $f(x) = 0$ has exactly one real root, then $a > 0$.
III: If $a < 0$, then $f(x) = 0$ has three distinct real roots.


Which of these statements are true for all real values of $b$?
  1. none of them
  2. I only
  3. II only
  4. III only
  5. I and II only
  6. I and III only
